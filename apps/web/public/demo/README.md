# Illustrative concept media

The ten JPGs in this directory are unchanged copies of existing AI-generated concept visuals in the user's separate `studio-ruaka-001-DELIVERY` and `Bedsitter-langata-001-DELIVERY` packages, specifically their `01-Rent-Fully-Furnished/photos-jpg` folders. The source package README/AI prompt/quality records describe them as AI concepts derived from supplied reference footage, proposed finishes, and virtual staging. They are not documentary photographs or proof of a completed/available property.

The source images were visually inspected before copying. `provenance.json` records the source filename and SHA-256 for each unchanged JPG. No vendor source code, vendor logo, customer media directory, external stock photograph or licensed font was imported for this visual redesign. The initials mark, page layouts and SVG UI icons are independently written.

All public screens label the catalogue synthetic and the images illustrative. The same coherent concept family is intentionally reused across sample records, including records whose bedroom count/type does not describe these concepts. A gallery caption makes that reuse explicit. These images must be replaced with authorized, accurate media associated with real listings before production publication; they must never be treated as accepted processor assets in the database.

The design direction follows Realtime's known burgundy/neutral identity and familiar rent/buy flows. It is an independent proposed redesign, not a pixel-exact implementation of a reviewed Figma frame. It uses system sans-serif fonts; Avenir Next is not bundled.
