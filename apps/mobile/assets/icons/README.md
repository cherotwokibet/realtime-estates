# Synthetic mobile preview icons

These are generic vector house marks rasterized to 1024×1024 PNG for Expo's launcher and Android adaptive-icon inputs. The colors match the two existing synthetic demo palettes only. They are not supplied or approved logos. The paired `*-foreground.svg` leaves the background transparent for Android's adaptive-icon mask; the paired full SVG is the fallback/iOS square. Re-rasterize the SVG when changing the shapes, then keep the PNG siblings in sync.
