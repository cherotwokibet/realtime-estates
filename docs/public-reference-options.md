## Contract and public scope

`GET /v3/property-reference-options` is anonymous and uses the existing explicit synthetic reference moderation gate. Disabled mode returns 404 before querying SQL. Non-GET methods return 405; query parameters, bodies and fragments are refused. The trusted server tenant context is installed with actor null. The query reads only reference attributes from `app_api.public_listings_reference_v3`, so normal publication, availability, company isolation and approved historical-reference predicates apply. Neither private addresses nor the active/private catalogue are returned.

One materialized statement groups saved IDs over the unfiltered public projection. Location labels include available parent paths. Same-label distinct IDs remain distinct; if one stable ID has historical label variants, the lexically first saved public label under C collation is used deterministically. This is not a claim about the latest official taxonomy or location authenticity. Legacy unknown references and explicitly empty amenities contribute no fabricated choices. Paused/withdrawn/ineligible stock cannot contribute identities through the public view.

The response is `{ policy: 'synthetic-reference-options-v1', maximumPerCategory: 5000, options: { countyId, localityId, neighbourhoodId, amenityId } }`, with arrays of `{ id, label }`. SQL permits a 20,001st sentinel row so an overflow can be refused. The application refuses more than 20,000 total or 5,000 choices in any category; it does not truncate them silently. Rows must have exactly three enumerable data fields, valid IDs, unique identities across categories and nonempty normalized labels of at most 512 characters without control/unpaired-surrogate characters. Accessors are refused without invocation. A local two-second SQL statement timeout and 3 MiB response bound apply; these do not establish connection-acquisition deadlines, hosted load capacity or an unbounded taxonomy allowance.

The shared client's `getSyntheticReferenceSearchOptions()` fixes the route, refuses bearer tokens, validates the complete policy/limit/category/row shape, freezes results, and uses the bounded anonymous no-store transport.
