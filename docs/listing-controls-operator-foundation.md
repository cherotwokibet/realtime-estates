# Listing control operator foundation — 16 October 2026

The admin now has a retained-attempt model, bounded browser transport and two fixed proxy routes for availability/publication. This is infrastructure for the visible operator controls, which are not implemented in this checkpoint.

`prepareListingControlAttempt` freezes a detached exact original command. Ready attempts submit once; sending attempts cannot double-submit, recover or discard. An uncertain result retains operation/listing/kind/version/target and blocks discard. GET recovery or deliberate exact replay uses that unchanged original. Denied recovery leaves uncertainty intact. A known conflict/refusal is a received historical result. This in-memory object does not persist across tab closure and cannot itself prevent a UI from creating another attempt; the future component must retain one active object and guard replacement/navigation.

The browser transport sends only fixed same-origin POST/GET requests, omits credentials and never carries an upstream bearer token. It validates exact receipts, rejects duplicate/misbound/oversized responses, bounds response reads to16KiB and times out stalled fetch/reads. Cancellation before dispatch is known; interruption after dispatch remains uncertain for writes. Recovery errors stay read-only. No automatic retry occurs.
