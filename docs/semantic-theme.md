# Shared semantic theme foundation

`createTenantTheme` accepts the existing public company-brand schema and returns frozen semantic colors, spacing, typography, radii and minimum control size. `tenantThemeCss` maps those same values to fixed CSS variable names and units; native-facing values remain numeric where appropriate. Company names, contacts and arbitrary keys never enter generated CSS. These functions do not resolve a company or authorize data.

Primary, secondary, accent and background colors retain the configured six-digit values. Each has an independently selected black or white foreground. Links use the primary color only when its contrast against the configured background meets4.5:1; otherwise they use the readable background foreground. The surface palette is fixed white with dark text. The outline color contrasts against the configured background. This avoids treating a decorative gold accent as readable small text automatically.

Contrast uses the sRGB relative-luminance formula without threshold rounding. The normal-text4.5:1 threshold and the rule against rounding a failing value upward follow [W3C's explanation of WCAG contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). Color-pair tests do not establish complete WCAG conformance: rendered component states, font scaling, focus, non-color cues, assistive technology and actual devices still need integration and review. The48-unit control size is a platform design choice, not a claim that every rendered control satisfies a standard.

The existing public brand validator now accepts only exact own enumerable data fields in ordinary or null-prototype records. It rejects inherited, symbolic, hidden, missing and accessor fields before invoking a getter. Nested configuration is captured into detached frozen output. Unknown fields, private credentials, CSS injection and scriptable or credential-bearing logo URLs remain rejected.

240domain checks passed with zero failures/skips (five new checks overlap this total). Reference tests include exact21:1 black/white, identical-color1:1, the failing unrounded#777777-on-white boundary, two brand palettes, dark/light extremes, midtone accents, safe CSS mapping, frozen independent brands, and getter nonexecution. Workspace typechecks/package builds and final formatting are recorded in CONTINUATION.md.

This is a shared foundation, not an application-wide theme migration. Current web/admin/mobile composition has not been replaced, and no new browser or device result is claimed. The existing demo registry remains synthetic and does not acquire fabricated real-company contacts.
