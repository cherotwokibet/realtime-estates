# Mobile approved public catalogue

Checkpoint 149, 23 October 2026. Synthetic development preview only.

The mobile application now has an explicit public read mode using the same bounded API-client contract as the website. Its default illustrative experience remains available when no connected mode is configured. Invalid, orphan or production synthetic configuration produces an error rather than silently substituting demo stock.

The build configuration accepts `MOBILE_CATALOGUE_MODE=synthetic-reference-public-v1`, `MOBILE_API_ORIGIN` and optional `MOBILE_ALLOW_LOOPBACK_API=true|false` only with `NODE_ENV=development|test`. Runtime selection also requires the native development flag. The configured company determines branding; neither search text nor a device-supplied tenant header selects database authority. The API origin must already select the intended company. Only public configuration is placed in Expo extras. Loopback is an explicit local-development allowance; a phone's loopback address refers to that phone, so desktop loopback success does not establish device connectivity.

`src/reference-catalogue.ts` performs one anonymous, no-store SDK GET with the existing strict public projection/parser and 100-row bound. It preserves exact prices, calculated known subtotals, original approved reference labels, explicit legacy absence and approved empty amenities. It returns a generic error on transport, malformed/private additions or cancellation. Search covers only the loaded public location fields; a full page carries an explicit incompleteness warning.

The mounted native screen provides loading, generic error with manual retry, search, empty results, list-to-detail navigation, historical amenities and complete named-charge presentation. Quote-required amounts stay unknown, refundable deposits remain distinguished, and known subtotal labels do not imply all-in coverage. Photos are explicitly unavailable in this metadata-only preview. Contact, enquiry and booking remain disabled. No exact address or map pin is displayed.
