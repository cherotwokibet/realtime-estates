Provisional operator workflow: record an already-completed contact or attempt with channel (call,whatsapp,email,in_person,other), reported outcome (connected,no_response,left_message,wrong_contact,other), occurrence time and original notes. Taxonomy and operator acceptance remain open. A WhatsApp entry is a staff record, not a messaging integration or proof that the platform delivered a message. No contact is inferred from status changes.

Original receipt read additionally requires its original requester; current authorized team members can read applied contact entries through the bounded private feed.

Capture locks the enquiry, checks expected saved version and serializes the company/contact operation ID. Immutable typed columns compare original enquiry/requester/expected version/channel/outcome/canonical instant and exact raw notes on replay; changed original input/actor conflicts. First valid stale-version request stores a durable conflict with original request facts and observed version, entry null and no audit. Exact replay/read returns that historical result after later workflow changes. Applied receipt retains original request and original entry/time; no hidden retry or current-version substitution exists at SQL level.

Contact append deliberately does not change enquiry status,follow-up,assignment or version. Expected version is an authorization/concurrency snapshot, not an incrementing contact counter. Multiple distinct entries can reference one unchanged workflow version. Human-reported outcomes do not automatically mark contacted or qualified. Future occurrence times are rejected; dates must be finite millisecond UTC-representable values. Notes retain leading/trailing spaces and allowed newlines/tabs, require non-whitespace content,max2000 code points and reject unsafe controls. Audit contains operation/channel/outcome metadata and never note bodies. Immutable current records have no editing/deletion/correction workflow yet; lawful retention/correction handling remains release work.

Feed sorts newest recorded time first with stable operation-ID tie break, not occurrence time, so backdated entries remain honest. Limit1..100,at most limit+1,truthful truncated flag.
