The endpoint accepts `location`, `purpose`, `type`, `period`, `max`, `beds`, `privateBaths`, `sharedBaths`, `sort`, `limit` and `offset`. Unknown keys, duplicates, unsupported enums, malformed numbers and an encoded query above 8,192 bytes are rejected. Limit defaults to 24 and accepts 1–100; offset defaults to 0 and accepts 0–10,000. Offsets beyond this traversal bound require a future discovery strategy rather than an unrestricted expensive scan. Rooms use canonical integers 0–100: exact bedrooms, minimum private/shared bathrooms. Null counts never satisfy an explicit zero. Price maximum uses exact KES cents and requires sale, or rent with a period. Price ordering has the same explicit basis requirement.

`location` performs a literal case-insensitive substring search over public locality and structured county/town/area only, with a 160-character limit. SQL wildcard characters are escaped. Neither private addresses nor browser authority/context are searched. Every caller value is bound; view identifiers and sort clauses are application constants. Orders are catalogue approval time descending, case-folded title with C collation, or exact integer base price ascending/descending, each with listing ID as a deterministic tie-breaker.

One materialized-filter SQL statement computes the full matching count and ordered page from one statement snapshot, including the correct total for empty/out-of-range pages. The response is `{ policy: 'public-search-v1', items, total, limit, offset, sort, hasMore, maxOffset: 10000 }`. `hasMore` describes matching rows beyond this page; callers must also honor `maxOffset`. Separate requests can observe new stock and changed counts; this is not a retained cross-request snapshot or cursor lease. Existing trusted tenant context and publication/availability/disabled-tenant predicates remain enforced by the normal public security-barrier view. No private table read or privilege is added.

The runtime transaction sets a local two-second SQL statement timeout; this is not a connection-acquisition or end-to-end HTTP deadline guarantee.
