# Public enquiry intake recovery foundation — 12 October 2026

`RealtorApiClient.preparePublicEnquiry(input, idempotencyKey)` captures an immutable, validated copy of raw form values and the original UUID before transport. It is shared by web/mobile callers. No bearer token, tenant override or replacement key is accepted by its submit/retry methods.

The attempt progresses from ready to sending, then received, rejected or uncertain. Sending locks synchronously, including two clicks in the same event turn. A received attempt cannot send again. An uncertain attempt requires an explicit `retryOriginal()` action; there is no automatic retry. The same original body/key are replayed through POST, which can create the original enquiry if the first request never arrived. This is not a read-only lookup. A later rejection cannot prove an earlier uncertain submission did not commit, so uncertainty persists until a valid receipt is recovered.

Preparation retains raw spacing and spelling for the form; the existing SDK normalizes the immutable captured values for transport. It does not store contacts in browser storage or logs. Memory is lost on reload/crash. Do not present the attempt key as a public enquiry reference or save its raw contact payload in the delivery tracker.
