The caller explicitly chooses a limit; 20 remains the SQL default for direct database callers.

The fixed GET route is `/v2/staff/listings/:id/duplicate-candidates?listingVersion=1&revision=1&revisionVersion=2&limit=20`. Exact parameter names, order and canonical decimal spelling are required; aliases, encoding alternatives, duplicate or extra parameters, fragments, request bodies, cookies, idempotency keys, conditional headers and caller context headers are refused. Trusted configured tenant and verified actor enter the transaction; current admin is checked before the typed SQL read. Exactly one database projection is validated before transaction completion. SQL performs its own current-admin, enabled-company and exact latest-revision checks.
