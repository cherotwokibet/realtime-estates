# Private saved images in the admin gallery

12 October 2026. Local synthetic development flow; independently written replacement. Production sign-in, publication and device/operator acceptance remain separate gates. Original vendor resources/live services and the KES10,000 total monthly client-price baseline are preserved.

## Operator flow

Prepare, upload/verify and explicitly attach a fictional test image using the existing photo controls. Read the current gallery, compare it and explicitly choose the saved snapshot before its new photos appear. A successful attachment receipt does not silently adopt another editing version.

Accepted sealed photos on the current saved draft display as private thumbnails, with their description, order and cover badge. Default metadata-only fixtures retain labelled placeholders and request no bytes. Local text changes and proposed photo order do not select another image version or trigger reads.

**Reload photo previews** explicitly reads the same saved version again; it does not save text, reprocess an image, repeat a pending command or adopt a newer version. Loading, unavailable and stale states are visible. An observed version conflict clears previews and pauses writes; use **Check saved version** and the existing comparison flow. An observed permission/resource denial clears the batch's previews and pauses writes without revealing a private cause. Original upload/gallery operation locks remain intact. Keep-text adoption retains raw invalid strings for later correction and a separate save.

## Shared transport and server boundary

`RealtorApiClient.getStaffMediaPreviewV2` sends a bodyless authenticated GET to the exact saved resource, with a canonical string `X-Revision-Version`. Per-call identity, origin restrictions, no-store and redirect refusal remain enforced. Success is read incrementally under declared/actual length, 10MiB, cancellation/deadline and WebP framing checks; error JSON is separately bounded and validated. The narrow result describes the requested tuple/version and owned bytes, not independently echoed SQL provenance. Reads have no uncertain-write flag and perform no retries. Existing JSON write semantics remain unchanged.

The development-only Next route uses the configured server identity behind the existing exact loopback Host/instance/origin/fetch-site policy. Browser Authorization, cookies, query/version aliases, body framing, ranges, conditional selectors, content encoding and Expect cannot select upstream access. Browser-controlled Accept-Encoding is not forwarded; encoded upstream image responses are refused. Only the requested resource, exact saved version and request cancellation cross the shared client boundary. Success returns private/no-store/nosniff WebP, owned bytes and the validated requested version header. No bearer, storage path/key, output/root/worker identity or public image locator enters a browser URL.

The underlying API/SQL checks current staff and current draft association/version before and after configured store reads, joins immutable attachment/capture/seal/output facts and independently verifies actual bytes. See [private-media-preview.md](private-media-preview.md) for that separate backend proof.

## Browser lifetime

Image batches are scoped to preview instance, listing, revision, saved version and media IDs. At most two reads are admitted concurrently in a batch, with at most twelve validated records. Scope changes, observed stale/denied results and unmount abort obsolete loads and revoke owned Blob URLs. Late completions cannot become current images; decode failure releases its URL and shows unavailable without automatic retry. Explicit reload starts a fresh read batch. These limits are not a global memory/admission guarantee or proof that a remote caller honors cancellation.

No polling detects every later permission change. Delivered bytes cannot be remotely unseen. The UI clears URLs on observed invalidation and checks the new scope when explicitly reloaded/adopted; continuous authorization or zero browser retention is not claimed. Default production routes remain unavailable.
